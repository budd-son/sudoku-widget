# Sudoku desktop widget

Небольшое настольное приложение на JavaFX для игры в судоку. Виджет работает в отдельном прозрачном окне, которое можно перемещать за заголовок и менять в размере, перетаскивая его края или углы.

## До изменений

- Окно было прозрачным, но перетаскивание было подключено ко всей сетке: ввод цифр и перемещение окна мешали друг другу.
- Размер окна нельзя было надёжно менять за край.
- Сохранение и загрузка существовали как неиспользуемые методы: кнопок не было, данные сохранялись относительно рабочей папки, а исходные подсказки терялись.
- Состояние игры и генерация зависели от общей статической доски.
- README и автоматические тесты отсутствовали. REST API в проекте изначально нет.

## После изменений

- Окно перемещается за заголовок, а размеры меняются перетаскиванием любой грани или угла; заданы минимальные размеры.
- Управление включает новую игру, подсказку, явное сохранение и загрузку.
- Состояние автоматически сохраняется после изменения клеток и геометрии окна, восстанавливается после перезапуска и включает исходную доску, введённые значения, сложность и размеры/положение окна.
- Сохранение атомарное и хранится в `~/.sudoku-widget/game.properties`; повреждённое сохранение отображается как ошибка, а не игнорируется молча.
- Логика игры и хранилище отделены от UI; генератор меняет переданную ему доску, а не глобальное состояние.
- REST API не добавлялся: его в исходном настольном проекте не было. Вместо API-тестов добавлены unit- и интеграционные тесты решателя, игровой логики и сохранения.

## Сборка и запуск

Нужны JDK 25 и Maven 3.9 или новее.

```shell
mvn test
mvn javafx:run
```

## Эксперимент

Автоматический эксперимент выполняется командой `mvn test`: она проверяет решение судоку, корректность генерации, подсказки, запрет изменения исходных цифр, распознавание решённой доски, полный цикл сохранения/загрузки и обработку повреждённого файла. Последний запуск `mvn clean test` завершился успешно: **9 тестов, 0 ошибок и 0 пропусков**.

Ручная проверка интерфейса:

1. Запустите `mvn javafx:run`, перетащите окно за надпись «Судоку», затем измените его ширину и высоту, потянув за край или угол.
2. Введите цифру, переместите окно и измените его размер. Нажмите «Сохранить», закройте приложение и запустите снова.
3. Убедитесь, что доска, введённые цифры, сложность, положение и размер окна восстановились. Кнопка «Загрузить» восстанавливает последнее сохранённое состояние и в уже открытом окне.
